# Docs

Docs for my personal programming paradigms.

- [Home](docs/README.md)

## Installation

```sh
cargo install --git https://github.com/CoolTrainerEX/docs.git
```

It is better to build from source to avoid any build artifacts.

```sh
git clone https://github.com/CoolTrainerEX/docs.git
cargo install --path docs
rmdir docs
```
