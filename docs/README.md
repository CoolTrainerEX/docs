## WSL

[Snap](https://snapcraft.io/) and [Apt](https://wiki.debian.org/AptCLI) is used for installing packages.

## Upgrading

Snap automatically upgrades.

```sh
sudo apt update
sudo apt upgrade
sudo apt clean
sudo apt autoremove
```
