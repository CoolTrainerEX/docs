# Tauri

Tauri is used to make GUI apps.

- [NextJS](nextjs/README.md)

## Usage

### Initialization

```sh
pnpm create tauri-app <name>
cd <name>
pnpm create @eslint/config
```

#### Create

- [`.vscode/launch.json`](create/.vscode/launch.json)
- [`.vscode/tasks.json`](create/.vscode/tasks.json)
- [`.github/workflows/tauri.yml`](create/.github/workflows/tauri.yml)

### Run

```sh
pnpm tauri dev
```

### Build

**GitHub Actions**, or:

```sh
pnpm tauri build
```
