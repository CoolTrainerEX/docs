# Tauri

Tauri is used to make GUI apps.

- [NextJS](nextjs/README.md)

## Usage

### Initialization

```sh
bun create tauri-app <name>
cd <name>
bun create @eslint/config
```

#### Create

- [`.vscode/launch.json`](create/.vscode/launch.json)
- [`.vscode/tasks.json`](create/.vscode/tasks.json)

### Run

```sh
bun run tauri dev
```

### Build

**GitHub Actions**, or:

```sh
bun run tauri build
```
