# JavaScript

JavaScript is used for frontend web development.

- [NextJS](nextjs/README.md)
- [Tauri](tauri/README.md)

## Installation

Install [pnpm](https://pnpm.io/). For CSS Preprocessor, install [Sass](https://sass-lang.com/).

## Usage

### Initialization

Follow individual initializations, or:

```sh
npm init
```

#### Dependencies

```sh
pnpm add <dep1> <dep2>
pnpm add -D <dep3> <dep4> # dev dependencies
```

[Dependencies](deps.json)

## Docs

```sh
deno doc
```

## Upgrading

After upgrading, run:

```sh
pnpm update -g
pnpm store prune
```
